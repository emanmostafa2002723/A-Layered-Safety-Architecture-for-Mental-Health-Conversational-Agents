# Results for response policy

**No experimental result is supplied by this scaffold.** Do not cite these folders as completed evidence.

Create a folder such as `2026-10-20_short_trial_seed42/` for each real run. Include:

- `EXPERIMENT_CARD.md` from the [template](../../templates/EXPERIMENT_CARD.md).
- A completed run manifest based on [this example](../../templates/run_manifest.example.json).
- Metrics with sample counts and definitions; safe plots/tables; sanitized synthetic per-case predictions where permitted.
- Exact input versions/configs, checkpoint/calibration hashes, code commit and commands.
- A clear note on failures, incomplete runs, selection bias and whether this is validation, calibration or untouched final-test evidence.

Keep earlier failed/negative trials identifiable. Summaries must link the actual results rather than relabel a different run as final. No model weights, optimizer states, sensitive logs or real participant messages belong here.
