# Attribution and sharing boundaries

This source-only export reuses the team's classifier, retrieval and output-checking code. Preserve existing source notices and docstrings. Model and dataset licenses are separate from the application's source code and must be reviewed before public distribution. No new project-wide license is granted by this export.

- Mistral-7B-Instruct-v0.3 and the Phoenix V6 adapter: external runtime assets, not bundled here.
- Fresh crisis and final boundary checkpoints, tokenizers and calibration: external runtime assets, not bundled here.
- all-MiniLM-L6-v2 and bge-reranker-large: external Hugging Face runtime assets, not bundled here.
- Qwen3 4B/Ollama: external service/model asset, not bundled here. Routing and output checking remain different prompts/tasks using the same pinned model.
- Processed RAG text/index files and training/evaluation datasets: not included in the source upload. Access does not imply redistribution permission.
- NORA interface images and external video thumbnails: credits and source links are in `docs/ASSET_CREDITS.md`. Retain those credits and review image/thumbnail use conditions before public publication.

This folder contains no intentional private account database, encryption key or raw conversation-log export. The automated source audit is a packaging check, not legal or privacy certification. Team permission and a publication review are still required before making the repository public.
